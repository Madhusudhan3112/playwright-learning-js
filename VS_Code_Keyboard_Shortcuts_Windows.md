## Tips & Tricks

- **Chord Keybindings**: Some shortcuts like `Ctrl + K Ctrl + S` are "chords" — press the first combo, release, then press the second combo.
- **Custom Shortcuts**: Open `File > Preferences > Keyboard Shortcuts` (or `Ctrl + K Ctrl + S`) to customize any shortcut.
- **Keybinding JSON**: You can also edit `keybindings.json` directly for advanced customizations.
- **Context-aware**: Some shortcuts behave differently depending on the active panel (editor vs terminal vs explorer).
